# Contributing to MotoNav

Thanks for your interest in contributing to MotoNav.

## Areas for Contribution

* Flutter UI improvements
* BLE reliability
* ESP32 firmware optimization
* Navigation accuracy
* UI animations
* Offline map support
* Hardware enclosure/PCB designs

## Setup

```bash
git clone https://github.com/IamThejus/motonav.git
cd motonav
flutter pub get
flutter run
```

## Pull Requests

* Keep PRs focused and small
* Write clear commit messages
* Test before submitting
* Maintain the existing design language

## Issues

Feel free to open issues for:

* bugs
* feature requests
* hardware ideas
* UI improvements
